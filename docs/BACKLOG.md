# Бэклог

## Главный экран «Карта серверов» (по макетам от 17.11.2026)

Пользователь прислал два макета. Бренд и тексты в них чужие, берём только идею и раскладку.

**Верх**
- Шапка: знак и название, справа уведомления и меню «…».
- Карточка статуса на всю ширину: кнопка питания, «Не подключено / Выберите сервер», стрелка вправо.
- Строка из трёх колонок: «Ваш IP», «Местоположение» (флаг, страна, город), «Протокол» с выпадающим списком.

**Центр: визуализация**, два варианта (оба хотим, переключатель):
1. «Галактика»: светящееся ядро в центре, вокруг орбиты и тонкие линии-связи. Серверы — плашки с флагом, кодом страны и пингом, они «летают» по орбитам. Выбранный сервер соединяется дугой с центром.
2. «Глобус»: тёмная Земля в сетке из точек, огни городов. Дуга от «вас» до сервера, плашка с флагом, пингом и мини-графиком.

**Низ: шторка** с ручкой, тянется вверх.
- Вкладки «Серверы / Маршруты / Избранное» и поиск.
- Серверы: фильтры по регионам (Все / Европа / Азия / Америка), кнопка «Самый быстрый». Таблица: звезда, флаг, страна и город, бейджи маршрута (протокол, скорость), пинг цветом, радиокнопка.
- Маршруты: схема «Вы → Relay → Сервер» и режимы «Оптимальный / Низкая задержка / Сбалансированный / Безопасный (через relay)» с пингом у каждого. В нашей модели relay — это цепочка из двух серверов (proxySettings в Xray).

**Нижняя панель**: слева настройки, по центру большая кнопка «Connect», справа избранное.

**Что нужно в ядре**
- Страна и город сервера: флаг-эмодзи или код в названии, иначе GeoIP-база, иначе резолв адреса.
- Регион сервера для фильтров.
- Пинг всех серверов фоном, когда VPN выключен.
- Цепочки серверов для режима «через relay».
- Внешний IP и местоположение до и после подключения.

**Требования**
- iOS 16+: SwiftUI Canvas с TimelineView; при Reduce Motion анимации нет.
- Памяти — только в приложении, расширение VPN это не затрагивает.
