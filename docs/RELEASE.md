Первая сборка Paradise для iOS 16–27.

**Что есть**
- Подписки по ссылке, конфиги текстом (vless/vmess/trojan/ss, Base64, Xray JSON), файл и QR-код.
- Обновление подписок при запуске и вручную, трафик и срок подписки из заголовков провайдера.
- Серверы: поиск, избранное, сортировка, проверка задержки через сам сервер.
- Подключение одной кнопкой через Network Extension и Xray-core 26.10.21.
- Режимы: весь трафик или правила из подписки. Строгий режим (kill switch).
- Перенос профиля: QR, ссылка `paradise://`, код, файл `.paradise`, меню «Поделиться». Предпросмотр, пароль, срок действия, выбор состава, слияние или замена. Совместимость с кодами SVOI1.
- Тёмная и светлая темы, русский и английский, Dynamic Type, VoiceOver, Reduce Motion.

**Какой файл ставить**
- `…-trollstore.tipa` — для TrollStore. Внутри уже есть все нужные права: Network Extension, `application-identifier`, группа Keychain.
- `…-unsigned.ipa` — для переподписи своим сертификатом. Подпишите приложение и `PlugIns/PacketTunnel.appex` профилями с правом Network Extension (`packet-tunnel-provider`).

**Диагностика**
Долгое нажатие на заголовок «Paradise» или Настройки → Диагностика. Там самопроверка всех частей, проверка загрузки подписок, тест VPN-подключения, детектор зависаний интерфейса и консоль логов (приложение, ядро, расширение, Xray). Отчёт копируется одной кнопкой, секреты из него вырезаются.

**Ограничения iOS**
- Выбор отдельных приложений для VPN на iOS возможен только через MDM, его нет.
- Базы geoip/geosite пока не встроены: такие правила из подписок пропускаются (приложение об этом пишет).
