Paradise 0.3.1 для iOS 16–27.

**Что нового в 0.3.1**
- Тап по стране на карте снова подключает её самый быстрый сервер, долгое нажатие открывает меню страны.
- Размеры и интервалы текста подогнаны под макет, дуги карты мягче, центр не пересвечен.
- Сервер без страны показывает адрес под названием, Hysteria2 — чип QUIC.
- Экран сразу обновляется после быстрого запуска (без «вечного» индикатора загрузки).


**Новая главная (по макету)**
- Карточка статуса с кнопкой питания, строка «Your IP / Location / Protocol», карта со странами (флаг, код, пинг) и дугами к центру.
- Панель «Servers / Routes / Favorites»: поиск, регионы All / Europe / Asia / Americas, «Fastest», сортировка по пингу, звёзды избранного.
- Внизу: настройки (ползунки), Connect, звезда для текущего сервера. Боковой панели больше нет — настройки, конфиги и данные открываются кнопкой с ползунками.
- В списке страна и город (из названия сервера или по IP), протокол и скорость канала, если провайдер её указывает. Пинг на карте и в списке один и тот же.
- Меню «Protocol» фильтрует серверы по протоколу. Интерфейс по умолчанию на английском, русский включается в настройках.

**Ядро**
- Проверка полей VLESS / Reality / TLS / WireGuard (в том числе файлов .conf), DNS по правилам Shadowrocket (bypass-tun, `#proxy`, quic, резервные DNS), update-url с интервалом.
- Совместимость с Xray 26: вместо `allowInsecure` — привязка к сертификату (`pcs`, `pinSHA256`).

**Какой файл ставить**
- `…-trollstore.tipa` — для TrollStore (все права уже внутри).
- `…-unsigned.ipa` — для переподписи своим сертификатом с правом Network Extension.

**Ограничения**
- DNS по DoT (`tls://`) Xray не поддерживает: такой сервер пропускается с предупреждением, остальные DNS работают.
- Город сервера по IP определяется через ipinfo.io (запасной — ipwho.is); это можно выключить в настройках обновления подписок.
- Apple TV, виджет, модули Shadowrocket и Tailscale недоступны.
- Пинг TCP при включённом VPN идёт мимо туннеля (через Wi-Fi или сотовую сеть).
