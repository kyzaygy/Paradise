Paradise 0.4.0 для iOS 16–27.

**Что нового в 0.4.0**
- Главный экран крупнее: текст, кнопки, флаги и строки списка увеличены.
- Живой космос: галактика вращается, по орбитам летят кометы, мерцают звёзды, ядро «дышит», при запуске вид вылетает из ядра, к подключённой стране бежит поток данных. Выключается в «Настройки → Оформление» (и «Уменьшением движения» iOS).
- Темы: Графит, OLED, Туманность, Аврора, Солнце и Светлая — в «Настройки → Оформление» и в меню «…».
- Карточка подключения без кнопки питания: состояние показывает огонёк (серый, мигающий жёлтый, зелёный), подключение — кнопкой Connect внизу. IP, локация и протокол — в той же карточке.
- Страны на карте стоят на орбитах и не налезают друг на друга; если все не помещаются, остаются самые быстрые.
- Пинг окрашен по качеству, выбранная строка подсвечена, у поиска есть кнопка очистки, в меню строки — «Скопировать адрес».
- Исправлено: после закрытия поиска панель возвращается на прежнюю высоту; карта под открытой панелью больше не попадает в VoiceOver.

**Ядро**
- Проверка полей VLESS / Reality / TLS / WireGuard (в том числе файлов .conf), DNS по правилам Shadowrocket (bypass-tun, `#proxy`, quic, резервные DNS), update-url с интервалом.
- Совместимость с Xray 26: вместо `allowInsecure` — привязка к сертификату (`pcs`, `pinSHA256`).

**Какой файл ставить**
- `…-trollstore.tipa` — для TrollStore (все права уже внутри).
- `…-unsigned.ipa` — для переподписи своим сертификатом с правом Network Extension.

**Ограничения**
- DNS по DoT (`tls://`) Xray не поддерживает: такой сервер пропускается с предупреждением, остальные DNS работают.
- Город сервера по IP определяется через ipinfo.io (запасной — ipwho.is); это можно выключить в настройках обновления подписок.
- Apple TV, виджет, модули Shadowrocket и Tailscale недоступны.
- Пинг TCP при включённом VPN идёт мимо туннеля (через Wi-Fi или сотовую сеть).
