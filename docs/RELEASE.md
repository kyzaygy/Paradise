Paradise 0.2 для iOS 16–27.

**Главная**
- Галактика вместо кнопки: страны из ваших подписок появляются на ней сами (по флагу, коду или городу в названии сервера), с пингом и полосками сигнала.
- Щипок — масштаб, два пальца — вращение, свайп — перемещение, двойной тап — сброс. Параллакс при наклоне телефона.
- Тап по звезде в центре — подключить/отключить, тап по стране — самый быстрый сервер этой страны.
- Сверху ваш IP, локация и протокол. Колокольчик — объявления провайдера, срок подписки, трафик, ошибки.
- Нижняя панель «Серверы / Маршруты / Избранное» с поиском, регионами и сортировкой по скорости. Свайпом вниз прячется.

**Четыре раздела слева**
- **Конфиг** — правила в формате Shadowrocket: `[General]`, `[Rule]`, `[Host]`. DOMAIN, DOMAIN-SUFFIX, DOMAIN-KEYWORD, DOMAIN-WILDCARD, IP-CIDR(6), GEOIP, GEOSITE, DST-PORT, RULE-SET, DOMAIN-SET, FINAL. Конфиг по ссылке с обновлением, из буфера, из файла. Проверка с номерами строк. Гео-база geoip/geosite (Loyalsoldier или runetfreedom).
- **Данные** — резервная копия в iCloud Drive через «Поделиться», журналы (прокси, DNS, ядро, автоудаление), импорт/экспорт серверов (ссылки или Xray JSON), перезапись и авто-переименование, удаление всех серверов, статистика трафика.
- **Настройки** — язык, метод теста (TCP или через прокси), быстрые команды и Siri, оформление, «По требованию» с доверенными Wi-Fi, туннель (MTU, IPv6, DNS, kill switch, APNs), локальный HTTP/SOCKS-прокси с доступом из сети, TCP (Fast Open, keep-alive, Mux, фрагментация TLS), UDP (ретрансляция, блокировка QUIC), разрешения, обновления, «Исключить маршруты 0.0.0.0/31» и «Включить маршруты 10.7.0.1/32» (для StikDebug/SideStore), автоповорот, сторонние клавиатуры, тактильный отклик.

**Протоколы и ссылки (как в Happ и не только)**
- VLESS (Reality, XHTTP, gRPC, WS, HTTPUpgrade), VMess, Trojan, Shadowsocks (вкл. 2022), SOCKS (вкл. варианты в Base64), Hysteria2 (порт-хоппинг, salamander), WireGuard.
- Параметры в имени: `#Имя?serverDescription=…&fragment=…&noises=…`.
- Профили маршрутизации `happ://routing/add|onadd|off` — из ссылки, из тела подписки или заголовка `routing`.
- Ссылки приложений `happ://add/…`, `v2raytun://import/…` и т. п. Зашифрованные `happ://crypt…` открыть нельзя — приложение скажет об этом.

**Какой файл ставить**
- `…-trollstore.tipa` — для TrollStore (все права уже внутри).
- `…-unsigned.ipa` — для переподписи своим сертификатом с правом Network Extension.

**Ограничения**
- Apple TV, виджет, модули Shadowrocket и Tailscale недоступны.
- Пинг TCP при включённом VPN идёт мимо туннеля (через Wi-Fi или сотовую сеть).
